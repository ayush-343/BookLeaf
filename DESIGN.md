# BookLeaf interface

The visual reference is [BookLeaf Publishing’s homepage](https://www.bookleafpub.in/). It uses Lato, coral (#f16876), white and blush surfaces, pill-shaped actions, and a compact wordmark. The portal uses a deeper coral (#a93248) for interactive controls and headings to meet contrast requirements. The header and sign-in use the public logo asset from the homepage.

The author book list foregrounds royalty balances. The staff conversation and reply editor sit beside book facts and policy. At narrow widths, context stacks beneath the conversation. Use sentence case labels, visible focus, and text for status.
